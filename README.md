# BellaFiat Website

Static website assets for the BellaFiat site. This repository contains the HTML pages and related assets that make up the public-facing site.

## Contents

- `index.html` – landing page
- `About.html` – about page
- `Collections.html` – collections page
- `Gallery.html` – gallery page
- `Contact.html` – contact page
- `Reviews` – reviews content
- `Testimonials.html` – testimonials page
- `Custom Designs.html` – custom designs page
- `Photos/` – photo assets

## Viewing locally

Open any HTML file directly in your browser (for example, `index.html`).

```bash
open index.html
```

On Linux, replace `open` with `xdg-open`. On Windows, use `start`.

## Notes

This repository is a static site and does not require a build step.
